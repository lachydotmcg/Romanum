# Roblox thumbnail design

Start with the actual game fantasy, one recognisable action and the feature that makes it distinct. Establish the intended audience and placement. Request existing screenshots or authorised assets when needed to represent the game accurately.

## Evidence before style

Classify each reference: owned experiment with impressions/clicks and dates, authorised visual inspiration, or an unmeasured public thumbnail. Popularity of the game is not thumbnail CTR. Call a reference high-performing only when its measurement, audience, placement and test window support that description. With no such dataset, use composition hypotheses and propose a test; never fill in a CTR or imply a visual score predicts clicks.

Study the communication rather than copy the image: focal action, readable expression, contrast, scale, and how the title and image complement each other. Use third-party assets only with appropriate rights. Distinctive characters, branding and layouts are not free assets merely because they appear in a reference.

## Concepts, generation, review

Propose a few genuinely different concepts, each with one testable reason: an understandable transformation, a clear challenge, or an action seen from the player's role. Select a concept against the brief before spending on detailed variants. When the developer has authorised autonomous selection, the agent can perform that review within the agreed budget; otherwise present it for review.

Write a generation brief with subject/action, composition, actual game art direction, focal hierarchy, expression and exact minimal text if needed. Generate only through an available, configured provider and authorised credit budget. A prompt draft is not a generated image. Review the result at small mobile size: is the action understandable, are faces/text readable, and does it promise gameplay the game delivers? Avoid deceptive rewards, fake Roblox UI, inaccessible text and frightening material unsuitable for the selected audience.

Test concepts against the same placement/audience where possible. Track exposure, qualified plays or clicks using the metric actually provided; do not treat CTR and qualified play-through as interchangeable. Separate creative effects from traffic mix, concurrent updates and sampling noise. State a stopping rule before testing; an early winner is not a guaranteed improvement.
