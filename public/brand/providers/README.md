# Provider marks

These decorative marks identify the model provider/product beside the model's readable name. They are not Romanum branding and do not imply endorsement. The original SVG geometry is retained; CSS masks render one monochrome tone inherited from the row, including its unavailable state. The same assets work as light marks on dark surfaces or dark marks on light surfaces.
